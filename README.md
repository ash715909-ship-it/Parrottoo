# Parrottoo 🦜

**Parrottoo** is a multilingual personal AI assistant designed to run seamlessly as a native-feel Progressive Web App (PWA) on iOS and other mobile devices. Powered by the Gemini API, Parrottoo acts as your personal, study, business, and research assistant.

---

## 🌟 Key Features

* **Multilingual Support:** Fluent in **English**, **Bengali (বাংলা)**, and **Arabic (العربية)** with automatic script detection and spoken audio responses.
* **Voice Integration:** Built-in speech-to-text voice recognition and text-to-speech output.
* **File & Document Reader:** Upload and query PDF or text documents directly in chat.
* **Smart Reminders:** Automatically generates Apple Calendar/ICS events from chat prompts.
* **Mobile-First Design:** Optimized for full-screen use via iOS Safari's "Add to Home Screen" feature.

---

## 🚀 Quick Setup & Deployment

1. Clone or download this repository.
2. Replace `"YOUR_GEMINI_API_KEY"` in `index.html` with your API key from [Google AI Studio](https://aistudio.google.com/).
3. Push `index.html` to a public GitHub repository.
4. Enable **GitHub Pages** in your repository settings (`Settings > Pages > Branch: main`).
5. Open your live GitHub Pages link in **Safari on your iPhone**, tap **Share**, and select **Add to Home Screen**!
